# FBI Huisrekening

Afgeschermde maandrekening van het FBI-huis. De gegevens staan versleuteld in `index.html` en zijn alleen met het huiswachtwoord te openen.

De site wordt elke maand opnieuw gemaakt met `fbi_site.py` (uit de gegevens van het huisrekening-dashboard). Pas `index.html` niet met de hand aan.
