Hier stel je de maand op en publiceer je hem naar het overzicht van de huisgenoten.

Hoe maak ik een GitHub-token?
  1. Ga naar GitHub → Fine-grained token.
  2. Repository access: Only select repositories → MatejaCoder/FBI-Huisrekening.
  3. Permissions → Repository → Contents: Read and write.
  4. Maak de token aan en plak hem hierboven. Hij blijft alleen op dit apparaat bewaard.
